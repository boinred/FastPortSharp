# case-01-simple

Happy-path scaffold with `--no-git --skip-smoke`. The byte-identical
parity gate: bash and PowerShell scaffold scripts must produce the
same content (excluding `.git/`, `*.sln`, `bin/`, `obj/`).

Design Ref: §8.3 case-01.

`expected/sha256.txt` and `expected/tree.txt` are generated by
`run.{sh,ps1} --update-golden case-01-simple`.
